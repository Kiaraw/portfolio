# Portfolio – Kiara Wurtz

Portfolio personnel développé avec **Next.js**, présentant mon profil, mes compétences et mes projets réalisés dans le cadre de mes études et projets personnels.

🔗 **Lien du portfolio en ligne**  
https://portfolio-kiara-wurtz.vercel.app/  

---

## 🎯 Objectif

Ce portfolio a pour objectif de :
- présenter mon parcours et mon profil
- mettre en avant mes compétences en gestion de projet, UX/UI et développement
- détailler mes projets à travers des pages dédiées
- accompagner mes candidatures en alternance (janvier 2026)

---

## 🛠️ Technologies utilisées

- **Next.js 14**
- **React**
- **Tailwind CSS**
- **Framer Motion**
- **Radix UI**
- **Vercel**

---

## ✨ Fonctionnalités

- Page d’accueil avec présentation du profil
- Navigation fluide par ancres
- Mode clair / sombre
- Animations
- Section projets avec pages dédiées
- Téléchargement du CV

---

## 📁 Projets

Chaque projet dispose d’une **page dédiée** comprenant :
- le titre du projet
- son statut (en cours / terminé)
- une description détaillée
- les outils et technologies utilisés
- un PDF de présentation du projet

---

## 🚀 Déploiement

Le portfolio est déployé sur **Vercel**.  
Chaque mise à jour sur la branche main de Github déclenche automatiquement un nouveau déploiement.

Préparer les nodes modules :  
``cd .\portfolio\front``  
``pnpm i``

Pour lancer le code :  
``pnpm dev``
